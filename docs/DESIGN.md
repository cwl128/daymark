# 界面规格

通过内置 ImageGen 生成界面参考（ui-mockup），用于实现布局，不将截图作为真实控件。设计 brief：Daymark 离线桌面日历，中文界面，日/周/月，今日、创建按钮，时间轴、今日清单、下一项倒计时、左导航、悬浮侧栏/可退出全屏/编辑框配套状态。

白色 #fff 画布；冷灰 #f1f4f5 导航；文字 #202728；次级文字 #667276；边线 #dfe5e7；青绿 #197b69 主色；浅绿 #d7eee7、淡紫 #e6e0f8 区分日程。系统 sans，正文 14px，控件 14px，日期标题 28px，倒计时 34px，提醒计时 88px。间距 8/12/16/24/32；小圆角 8px，清晰焦点边框。

以导航 rail、时间轴、右栏三个区域分隔，不使用营销横幅或装饰插画。日程块为细色边，任务为真实 checkbox。符号图标为原生代码的日历/齿轮/箭头/加号，不依赖图像资产。主界面日期、条目、倒计时均来自真实数据，空数据库展示空状态。

为实现用户要求而补充：日期前后导航；跨日/深夜条目覆盖 00–24；周/月导航；无开始时间任务列表；表单错误与预览说明；可关闭的错误提示；设置声音/分钟与权限；小窗口堆叠布局。生成参考样例时间和数据不是预装数据。

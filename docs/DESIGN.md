# Daymark 0.1.1 界面规格

本轮根据 ImageGen 配套参照实现主日历、设置、紧凑侧栏、边缘把手、三步引导及深色模式。参照用于布局与视觉层次，不把生成截图作为控件，不导入示例日程；实际日期、任务、计时来自用户数据。

默认强调色 #4f6bed，浅色背景 #f8fafc，深色背景 #111827，默认跟随系统。统一 CSS 变量覆盖背景、表面、正文、次要文字、边线、强调色、选中状态及按钮文字。自定义颜色按实际亮度计算文字对比度；主按钮及选中条目独立计算文字颜色。设置保存到 SQLite，外观缓存仅用于首次绘制。主题变化同步到主窗、侧栏、提醒及引导。

主窗保留 176px 导航、时间轴与今日任务三个区域；设置按分隔线组织，主题三选一与三个原生颜色选择器即时预览。引导三步可跳过，桌面关闭与退出的区别直接说明。

侧栏宽 280 逻辑像素、内容自适应高 160–420，受显示器可用区域约束。12px 内边距，12px 正文，14px 标题，22px 倒计时。长列表内部滚动。收起时原生窗口宽 8、高 56，不用大窗口内的不可见区域模拟把手。悬停 250ms，离开 350ms，快速移动取消过时操作；点击交互才申请键盘焦点，图钉可保持展开。

视觉复核：与参照对照，主导航、分区、蓝灰配色、侧栏尺寸及三步引导一致。实际设置增加权限状态、错误详情与恢复默认入口；日历保留全天滚动及真实日期。窄屏 390px 无水平溢出。深色对话框显式使用主题表面色，避免系统默认背景与自定义颜色不一致。
